# Design Workspace

このフォルダはデザイナー向けの作業スペースです。デザイン仕様書、UI構成案、アセット管理などのドキュメントを配置します。

## フォルダ構成案
- `docs/`: 画面構成やUIコンポーネントの仕様（Markdown）
- `assets/`: 検討用の画像やアイコン案など
- `prototypes/`: 遷移図やワイヤーフレームなど
