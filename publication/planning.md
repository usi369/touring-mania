# 出版企画書：デザイナーのためのゲーム開発実践ガイド - ロジカルUIで作り切る「手触り」の正体

## 1. コンセプト
デザイナーが主体となって、効率的かつ「手触りの良い」ゲームを作り切り、リリースするまでのプロセスを体系化した実践書。
「なんとなく良い」を論理的に説明する手法（ロジカルUI設計）を武器に、エンジニアと対等に渡り合い、最短距離でリリースまで漕ぎ着けるためのサバイバル・ノウハウを公開。

## 2. ターゲット読者
- 自分のアイデアを形にし、リリースまで完遂したいデザイナー
- デザイナー主導のプロジェクトで、高いクオリティを実現したいエンジニア
- 「作りたいけど終わらない」悩みを持つ全ての個人開発者

## 3. 本書の特徴
- **完遂重視**: 単なるデザイン論ではなく、アセット管理からリリースまでの「工程」を重視。
- **ロジカルUI**: デザイナーの感性を数値や物理法則（Spring, Tilt等）で言語化し、実装への落とし込みをスムーズにする。
- **実例ベース**: 本プロジェクト『Touring Mania』の全工程を、成功も失敗も含めてドキュメント化。

## 4. 構成案（マイルストーン）
- **序章**: デザイナーはなぜゲーム開発のリーダーになれるのか
- **第1章：基盤構築**: スクロールを捨て、「ステージ」を定義する（固定アスペクト比のロジック）
- **第2章：手触りの実装**: 物理学で語るJuicy UI（スプリング・衝撃・タクタイル感）
- **第3章：エンジニアとの共創**: Tailwind CSSと共通言語化による効率的な開発
- **第4章：世界観の地続化**: 情報（ログ・地図）を物語に変えるデザイン・ハック
- **第5章：リリースの壁**: 最後の10%を仕上げるためのスコープ管理とメンタル
- **終章**: あなただけのガレージ（ゲーム）を世界に公開しよう
