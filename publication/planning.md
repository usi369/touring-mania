# 出版企画書：ロジカルUI設計 - エンジニアに伝わるデザインの正体

## 1. コンセプト
「なんとなく良い」を卒業し、全てのピクセルに理由を持たせる。
デザイナーの感性を論理的・工学的に言語化し、エンジニアがそのまま実装に落とし込める「ゲームUI設計フレームワーク」を提示する一冊。

## 2. ターゲット読者
- **エンジニア**: デザインを「論理」として理解し、自作ソフトのクオリティを底上げしたい方。
- **デザイナー**: エンジニアリングの制約を「表現の武器」に変え、円滑な共創を目指す方。
- **インディーゲーム開発者**: 少人数で「商業レベルの手触り（Juicy UI）」を実現したい方。

## 3. 本書の特徴
- **実践ベース**: 実際のゲーム開発プロジェクト『Touring Mania』の制作ログを元にした、嘘のない技術解説。
- **コード付き**: 全てのロジックに対応する React + Tailwind CSS + Framer Motion の実装例を掲載。
- **心理学×物理学**: ピーク・エンドの法則やスプリング物理など、UIに命を吹き込む学術的アプローチを解説。

## 4. 目次構成（抜粋）
- **第1章：レイアウトの工学**: スクロールを殺し、没入感を固定する。
- **第2章：手触りの物理学**: 「気持ちいい」を数値化する Juicy UI 実装。
- **第3章：情緒のエンジニアリング**: 勝利の黄金、敗北のグリッチ。
- **第4章：世界観の地続化**: 情報（ログ・地図）を物語のアセットに変える。
- **第5章：視聴覚の統合**: 0.1秒の同期が実体を生む。
