# 出版企画書：ロジカルUI設計 - エンジニアに伝わるデザインの正体（仮）

## 1. コンセプト
デザイナーの「感覚」を論理的・技術的に言語化し、エンジニアが納得し、そのまま実装に落とし込めるデザイン設計手法を体系化した一冊。

## 2. ターゲット読者
- 自分のプロダクトの「見た目」を論理的に改善したいエンジニア
- エンジニアリングへの理解を深め、円滑な連携を目指すデザイナー
- 技術書典で「実装に直結するデザイン知見」を求めている層

## 3. 採用案：『ロジカルに作る：エンジニアに伝わるゲームデザインとUI設計』
- **特徴:** デザイナーの「なんとなく良い」を徹底的に排除し、配色、配置、動き（アニメーション）の全てに理由（ロジック）を持たせる。
- **主な内容:**
    - 画面を「固定アスペクト比」にする論理的メリットと実装。
    - Tailwind CSS で定義する「デザインシステム」の設計。
    - Framer Motion で作る「気持ちいい」の正体（イージング、バウンドの数値化）。
    - アンカーポイント設計：ステージ端を基準にする理由。
- **強み:** 技術書典のメイン読者（エンジニア）の「なぜ？」に答え、実装可能なコードをセットで提供する。

## 4. 執筆・制作スケジュール（案）
- **フェーズ1:** 企画・リサーチ（現在）
- **フェーズ2:** 本プロジェクト（Touring Mania）の制作プロセスを「副産物」として記録
- **フェーズ3:** 執筆・図版作成
- **フェーズ4:** 入稿・頒布（技術書典などのイベントに合わせる）
