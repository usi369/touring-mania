# 出版企画書：デザイナーのためのゲーム開発実践ガイド（仮）

## 1. コンセプト
デザイナーが主体となって、効率的かつ「手触りの良い」ゲームを作り切り、リリースするまでのプロセスを体系化した実践書。

## 2. ターゲット読者
- 個人開発・少人数開発に挑戦したいデザイナー
- 自分のゲームの「見た目」や「触り心地」を改善したいエンジニア
- 技術書典などのイベントで、実践的な制作ノウハウを求めている層

## 3. 内容の方向性（案）

### 案A：『ゲームの「手触り」をデザインする：Juicy UI 実装ガイド』
- **特徴:** Balatroのような「動的な心地よさ」に特化。
- **内容:** アニメーションの「タメ・ツメ」、シェーダーによるネオン演出、フィードバックの設計理論と実装（Framer Motion等）。
- **強み:** 市場の需要（エンジニアの悩み）に直結し、視覚的な引きが強い。

### 案B：『デザイナーのためのインディーゲーム・サバイバルガイド』
- **特徴:** 制作プロセス全体を効率化。
- **内容:** スコープ管理、アセットのモジュール化、Figmaとコードの連携、リリースまでのタスク管理。
- **強み:** 「完成させる」ことに主眼を置いた実用書。

### 案C：『ロジカルに作る：エンジニアに伝わるゲームデザインとUI設計』
- **特徴:** デザイナーの「感覚」を「言語化」。
- **内容:** なぜその色なのか、なぜその配置なのかを論理的に解説し、そのまま実装に落とし込める設計手法。
- **強み:** 技術書典のメイン層（エンジニア）に最も「刺さる」可能性が高い。

## 4. 執筆・制作スケジュール（案）
- **フェーズ1:** 企画・リサーチ（現在）
- **フェーズ2:** 本プロジェクト（Touring Mania）の制作プロセスを「副産物」として記録
- **フェーズ3:** 執筆・図版作成
- **フェーズ4:** 入稿・頒布（技術書典などのイベントに合わせる）
