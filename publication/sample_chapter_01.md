# 第1章：レイアウトの工学 - 没入感の土台を作る

## 1.1 固定アスペクト比（9:16 ステージ方式）の論理的必然性

### Webサイトとゲームの「境界線」
Webデザインの世界では、情報の量に合わせてページが縦に伸びる「スクロール」が標準的な作法です。しかし、没入型のゲーム体験において、スクロールは往々にして「ノイズ」となります。

なぜなら、スクロールが発生した瞬間に、画面内の要素の相対的な位置関係が崩れ、プレイヤーの視線が「今、どこを見るべきか」という設計者の意図から外れてしまうからです。

### スクロールを殺し、世界を固定する
本作『Touring Mania』では、全ての画面においてブラウザ標準のスクロールを禁止し、**9:16の固定アスペクト比を持つ「ステージ（Stage）」** を中央に配置する手法を採用しました。

この設計には以下の論理的メリットがあります：

1.  **情報の焦点化**: 常に1画面内に全ての情報が収まっているため、プレイヤーは「探す」手間から解放され、「考える（戦術を練る）」ことに集中できます。
2.  **物理的シミュレーションの基盤**: 3D Tiltやカードの飛来演出など、物理的な動きは「枠（空間）」があって初めてその迫力を発揮します。
3.  **マルチデバイスでの一貫性**: スマホでは全画面、PCやタブレットでは左右に「背景の拡張」を設けることで、どのデバイスでも「同じ戦場」を体験させることができます。

### 実装のロジック（React & Tailwind CSS）
具体的には、`GameLayout` コンポーネントで以下のような制約を課しています。

```tsx
// 固定ステージの核心部
<div 
  className="relative w-full h-full aspect-[9/16] overflow-hidden"
  style={{
    maxWidth: 'calc(100vh * (9 / 16))', // 高さを基準に幅を制限
    maxHeight: '100vh',
  }}
>
  {children}
</div>
```

この「箱」を用意することで、デザイナーは「はみ出し」を気にすることなく、ピクセルパーフェクトなゲームUIを組み上げることが可能になります。
